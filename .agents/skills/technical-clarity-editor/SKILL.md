# Clarify Technical Docs

## Use This Skill

Use this skill when the user wants to lightly revise technical writing so it becomes easier to follow without losing precision.

Before rewriting, read [references/rewrite-rules.md](references/rewrite-rules.md).

Common cases:

- proposals
- design docs
- README files
- comments and docstrings
- policy or process notes

Follow applicable repository instructions, including [writing-style.instructions.md](../../../.github/instructions/writing-style.instructions.md), and preserve repository-specific terminology and scope.

## Output

When workspace editing is authorized, edit the requested document in place. Otherwise, return the revised document text and identify its intended path.
